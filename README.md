## Hi, I'm _inc0gnit0

I make small programs for Windows and a Linux distribution to go with them. Everything here is free, and everything is built to be used, not just looked at.

### Projects

| | What it is | Latest |
|---|---|---|
| [**OrkaPlayer**](https://github.com/cyz-yt/OrkaPlayer) | A media player for Windows built on VLC. Lyrics that sing along, podcasts, internet radio and TV, a tag editor, an equalizer and an oscilloscope drawn from the music itself. | [![OrkaPlayer](https://img.shields.io/github/v/release/cyz-yt/OrkaPlayer?label=&color=1D9E75)](https://github.com/cyz-yt/OrkaPlayer/releases/latest) |
| [**OrkaNote**](https://github.com/cyz-yt/OrkaNote) | A Notepad for Windows with tabs that come back after closing, colours for code, Run (F9) for scripts, macros and a dark theme. | [![OrkaNote](https://img.shields.io/github/v/release/cyz-yt/OrkaNote?label=&color=7F77DD)](https://github.com/cyz-yt/OrkaNote/releases/latest) |
| [**OrkaLinux**](https://github.com/cyz-yt/OrkaLinux) | A Linux distribution built on Debian 13 with KDE Plasma 6. Firefox, Discord, VLC and LibreOffice out of the box, and it installs with Secure Boot on. | [![OrkaLinux](https://img.shields.io/github/v/release/cyz-yt/OrkaLinux?include_prereleases&label=&color=378ADD)](https://github.com/cyz-yt/OrkaLinux/releases/latest) |
